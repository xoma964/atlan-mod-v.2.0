# Atlan Mech — мод для Minecraft Java (Fabric 1.21.1)

Гигантский костюм-мех Атлан высотой 7 блоков. Две версии: Mark 42 и Mark 85.

## Структура
Весь код — один файл `src/main/java/com/atlanmod/AtlanMod.java` (остальные классы — вложенные внутри него).
Текстуры, lang, рецепты и fabric.mod.json лежат отдельно в `src/main/resources/`.

## Сборка
JDK 21 + Gradle:
    gradle wrapper --gradle-version 8.10.2
    ./gradlew build        # jar в build/libs/
    ./gradlew runClient    # тест в игре
Jar + Fabric API 0.115.0+1.21.1 в папку mods/.

## Вызов
- Дуговой реактор (золото, редстоун, алмаз, незерит) → Mark 42: детали прилетают издалека и собираются вокруг тебя.
- Нано-реактор (дуговой реактор + 4 незерита + 2 звезды Незера + 2 алмазных блока) → Mark 85: костюм мгновенно собирается из наночастиц.
- ПКМ — вызвать, Shift+ПКМ — автономный режим вкл/выкл. У игрока один костюм: другая версия заменяет прежнюю.

## Внешний вид (как в Doom: The Dark Ages)
Зелёная броня с латунными акцентами, тёмные металлические суставы, рогатый шлем с откидной маской, двигатель на спине.
Mk42 — классический Атлан (оливковая броня, янтарное свечение). Mk85 — «королевская» версия
(глубокий изумруд, больше золота, бело-голубое свечение). Текстуры — в assets/atlan/textures/entity/.

## Управление внутри (обе версии, по мотивам Fiskheroes)
- WASD + мышь; ЛКМ — кулак (или удар мечом); Shift — выйти
- Полёт: двойной Space (или V). Ctrl (спринт) — ускорение. Shift/V выключает.
- J — режим парения (медленный точный полёт); A/A или D/D в полёте — бочка
- B — репульсор; N — юнибим (Mk85: заряд ~1 с, луч ~2 с); C — пластинчатый меч
- R — удар по земле; G — прыжок; K — маска (забрало) вкл/выкл
- X — покинуть костюм: он остаётся «сентри» (автономный режим: следует за владельцем и стреляет); ПКМ по нему — снова сесть
- Суперменская посадка: падение с высоты без урона и с ударной волной
- Пока пилот внутри: огнестойкость, дыхание под водой, большое снижение урона, регенерация костюма и пилота

## Только Mark 85 (Mark 50 + Mark 85)
Z — нано-щит; H — нано-молот; M — залп из крыльев.
Нано-реактор: ПКМ — собрать костюм из наночастиц, ПКМ внутри — разобрать (нанит-превращение вкл/выкл).

## Полёт сквозь блоки
В полёте костюм проходит сквозь блоки, пилот не получает урон от удушья. Приземлиться внутри блоков нельзя.
Если костюм оказался внутри блоков (в т.ч. после сборки), он сам включает полёт, чтобы выбраться.

## HUD и свечение
Внутри костюма слева на экране: здоровье костюма, статусы (полёт, меч, щит) и полоски кулдаунов способностей
с актуальными клавишами. Грудь, глаза, ладони, клинок и двигатель светятся (Mk42 — оранжевым, Mk85 — голубым)
и вспыхивают ярче при выстрелах, ударах, зарядке луча и сборке.

## Что подкрутить
Баланс — константы в entity/AtlanEntity.java; рост — HEIGHT там же; текстуры — assets/atlan/textures/.

## Сборка без установки Java/Gradle (через GitHub)
1. Создай бесплатный репозиторий на github.com и загрузи в него все файлы проекта (включая папку .github).
2. Открой вкладку Actions → дождись зелёной галочки у «Build mod» (3–6 минут).
3. Открой завершённый запуск → внизу «Artifacts» → скачай atlan-mod-jar → внутри atlan-mech-1.0.0.jar.
